Contribute

Your first pull request in 15 minutes.

The offline tests need no keys and cost nothing. Some of the most useful help needs no code at all: a real call on a machine we do not have, reported in an issue.

  1. Clone, and install uv (pinned, checked against its SHA-256; it does nothing if uv is there). 
    git clone https://github.com/ballerine-io/pointe.git && cd pointe
bin/install-uv
  2. Run the offline suite. About four minutes. Tests that need a key or Apple silicon skip themselves. 
    uv run --locked pytest -q tests/ --ignore=tests/e2e
  3. Run a daemon of your own, on its own port and state folder, so it never touches a Pointe you use. It needs one model key, from the Keychain or its environment variable. 
    export CLAUDE_VOICE_STATE="$(mktemp -d)" CLAUDE_VOICE_DAEMON_PORT=7870
bin/voice-daemon ensure
  4. Change one thing, test it, sign the commit (git commit -s, the DCO), and open a pull request. A maintainer reviews every one.

Where things live

daemon.pyThe hub: routes, the call pipeline, approvals, the status.
brain.pyDecides what to say. Speech is a tool call, so code checks a reply before anyone hears it.
guards.pyRules in code: what can be read out, what counts as a plain yes.
harnesses/One adapter per agent: Claude Code, OpenCode, Codex. The contract is docs/harnesses.md.
ui.htmlThe call page: one file, no build step.
ios/The iPhone app, in SwiftUI, with its tests.
tests/, bench/The offline suite, and the benchmarks behind every default. Synthetic data only.

The rules that matter

Rules live in code

If the bot must never do something, a test enforces it. A bug fix starts with the failing test. A feature may only narrow what a spoken word can approve, never widen it.

No new dependency without a yes

Ask in the issue first. Every download is pinned by hash, every host the code reaches is listed, and the page and this site load nothing from another host.

Ideas start in Discussions

Propose in Ideas, ask in Q&A. A vulnerability goes to private reporting, never an issue.
