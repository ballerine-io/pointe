# Every host the software can contact, one per line: host, whitespace, why. `*.` at the start matches any subdomain.
# A line that starts with `link` names a host that appears in the source only as text shown to a person (where to get a
# key, an XML namespace) and is never contacted. tests/test_supply_chain.py fails when a URL literal in the source names
# a host that is not here, so a dependency bump or a pull request cannot add an egress silently. The human-readable
# table, with when each is reached, is docs/security/supply-chain.md.
